# 🕵️ Справа про зниклі гроші

Особистий трекер витрат у стилі детективної справи: банківські виписки → SQLite-база → статичний сайт
з «дошкою підозрюваних», хронологією, розрахунком спільних витрат і сторінкою надходжень.

> Усі дані в цьому репозиторії **вигадані** (`demo_data.py`). Жодних справжніх виписок тут немає.

## Що є

- **site/index.html** — головна «справа»: топ магазинів, категорії, хронологія по місяцях, «вирок» — хто кому скільки винен за спільними картами, пошук по всіх витратах, режим приватності (ховає суми для скріншотів), UA/EN.
- **site/income.html** — надходження, скільки відкладено, інвестиції, залишки на рахунках.
- **site/schema.html** — як влаштована база.

## Швидкий старт (демо)

Потрібен лише Python 3.10+ (без сторонніх бібліотек).

```bash
python3 demo_data.py      # створює expenses.db з демо-даними
python3 build_site.py     # збирає сайт у папку site/
python3 -m http.server 8765 --directory site
```

Відкрийте http://localhost:8765.

## Зі своїми виписками

Трекер читає звичайні CSV-виписки, які дає майже будь-який банк в інтернет-банкінгу.

1. Відредагуйте **config.py**:
   - ваше імʼя й місто;
   - `CSV_FORMATS` — як називаються колонки у CSV вашого банку (дата, опис, сума) і як записана дата;
     якщо банків кілька з різними форматами — додайте кожному свій формат;
   - `RECIPIENT_CATEGORY` — перекази яким людям вважати витратами (родина, подарунки…);
   - `ACCOUNTS` і `INCOME_RULES` — для сторінки «Надходження».
2. Створіть порожню базу:
   ```bash
   rm -f expenses.db && sqlite3 expenses.db < schema.sql
   ```
3. Імпортуйте витрати з карток (останній аргумент — назва формату з `CSV_FORMATS`, якщо не `default`):
   ```bash
   python3 import_csv.py "виписка-карта1.csv" "Карта 1"
   python3 import_csv.py "виписка-карта3.csv" "Карта 3 (спільна)" mybank
   ```
4. Для сторінки «Надходження» імпортуйте виписки рахунків (`main`, `savings` або `spending`):
   ```bash
   python3 import_income.py main "виписка-рахунку.csv"
   ```
5. Позначте спільні карти (наприклад, навпіл із подругою):
   ```sql
   UPDATE cards SET split_with = 'Імʼя', split_share = 0.5 WHERE name = 'Карта 3 (спільна)';
   ```
6. `python3 build_site.py` — і сайт оновлено.

Свої магазини й категорії додавайте в `schema.sql` (таблиця `category_rules`) — правило «підрядок в описі → категорія».

## ⚠️ Приватність

`.gitignore` не пускає в git бази (`*.db`), виписки (`*.pdf`, `*.csv`) і скріншоти. Але згенеровані
`site/*.html` **містять усі ваші дані всередині** — не комітьте їх після імпорту справжніх виписок
(або додайте `site/index.html` і `site/income.html` у `.gitignore`).

## Файли

| Файл | Що робить |

| `import_csv.py` | імпорт витрат з CSV-виписки картки |
| `import_income.py` | імпорт надходжень і залишків з CSV-виписки рахунку |

| `build_site.py` | база → HTML-сторінки |
| `site/template.html`, `site/income-template.html` | шаблони сторінок |
